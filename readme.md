## Estructura del Proyecto

---

- **Desarrollo:** Contiene el código fuente del proyecto completo: [HTML](index.html), [CSS](styles.css) y [JavaScript](scripts.js). Para acceder a la página, recomiendo visitar el enlace ubicado al inicio de este README.

- **Documentación:** Contiene este README y una carpeta con capturas de pantalla que muestran la interacción entre el desarrollador y la IA, incluyendo los prompts utilizados y sus respectivas respuestas.

## Tecnologías Utilizadas

---

- **HTML5** (Estructura básica).

- **CSS** (Desarrollo visual).

- **JavaScript** (Desarrollo funcional y reestructuración del HTML al agregar botones, listas, identificadores y otros elementos dinámicos).

- **Git y GitHub** (Control de versiones local y almacenamiento seguro del proyecto en la nube).

- **GitHub Desktop** (Herramienta que facilitó el manejo de Git y GitHub de forma más eficiente).

- **ChatGPT** (IA principal utilizada para resolver problemas y errores durante el desarrollo).

- **Gemini** (Utilizado como simulador de teléfono móvil para realizar pruebas).

## Documentación del uso de la IA

---

El uso de la IA fue esencial gracias a la correcta aplicación de los prompts. Durante las primeras etapas del desarrollo, cuando el proyecto solo involucraba HTML y CSS básicos, su utilización no fue necesaria. Sin embargo, al comenzar a trabajar con JavaScript, incorporando botones, funciones y diferentes tipos de interacción con el usuario, ChatGPT se convirtió en una herramienta fundamental para:

- Utilizar correctamente las funciones de JavaScript.

- Realizar la sobrescritura correcta del HTML.

- Corregir errores durante el desarrollo.

- Explicar el funcionamiento de cada fragmento de código y su finalidad.

## Decisiones Técnicas

---

- **Utilización de JavaScript como protagonista del proyecto:** Una vez comprendido el funcionamiento de HTML, CSS y JavaScript, decidí desarrollar un proyecto donde JavaScript fuera el componente principal. Para ello, construí una base sólida en HTML que garantizara el correcto funcionamiento en distintos dispositivos e idiomas mediante la configuración del `<head>`, organizando la estructura con `header`, `main` y `footer`, y vinculando los archivos CSS y JavaScript necesarios para el funcionamiento del proyecto.

- **Utilización de ChatGPT:** Decidí utilizar esta herramienta porque me pareció muy didáctica y clara al explicar las decisiones que debía tomar. Explicaba el código línea por línea y, recién al final, proponía la solución completa. En muchas ocasiones, al comprender la explicación, el código ya estaba desarrollado por mi cuenta en Visual Studio Code antes de llegar a la respuesta final.

- **JavaScript como eje principal del proyecto:** Esta decisión estuvo orientada al aprendizaje, ya que JavaScript permite modificar, reescribir y ampliar funcionalidades sin afectar la estructura principal del proyecto. Además, fue utilizado para crear listas, identificadores, botones y muchas otras funciones que fueron surgiendo a medida que se pensaba el funcionamiento adecuado para el usuario.

- **Utilización de GitHub Desktop:** Al desempeñarme como desarrollador mientras trabajo en otra actividad, esta herramienta me permitió avanzar en el proyecto tanto desde mi casa como durante momentos libres en mi jornada laboral. También facilitó el uso de Git durante todo el desarrollo. Al trabajar desde dos computadoras distintas, GitHub resultó fundamental: cada cambio realizado en un equipo era enviado al repositorio mediante un *push* y, al día siguiente, podía recuperarlo en la otra computadora mediante un *pull*, manteniendo siempre el proyecto actualizado y sincronizado.
